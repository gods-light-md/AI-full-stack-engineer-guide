## How to use this pack (it is mandated to follow this as myself, I'm following it!)

1. Read `Realistic_Journey.md` once, fully, before touching `Weekly_Task_Guide.md`. It sets the map so the weekly grind has a destination.
2. Print or pin `Mistakes_And_Fixes.md` (mistakes) somewhere visible. Re-read it every 4 weeks — most mistakes happen *after* the honeymoon phase, not at the start.
3. Don't start `Professional_Influence_Building.md` (influence-building) until you're at least 3 weeks into building things. Influence without substance is noise and you might be given another junior eng there a roadmap to also joining the over-whelmed enthusiasts; the guide is written assuming you already have something worth sharing.
4. `Deep_Learning_Without_Rabbit_Holes.d` is your rule-book for saying "no" to shiny distractions. Read it whenever you feel the urge to switch courses/tutorials.
5. `Bonus_Extras.md` is optional but high-leverage — read it before your first job application, not after.
